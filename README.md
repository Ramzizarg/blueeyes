# BLUEEYES

Immersive Next.js agency site inspired by premium brand studios — full-viewport storytelling, cinematic motion, and a polished contact footer.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS v4
- Framer Motion

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```
